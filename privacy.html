Privacy Policy

Last updated August 7, 2026

Short version

This site is a simple landing page. It doesn't have accounts, doesn't run analytics, and doesn't set cookies of its own. Each game linked from here is a separate site or app with its own privacy practices — see below.

This site

plasticinegames.com is a static page listing my games and linking out to them. It doesn't collect names, emails, or usage data, and it doesn't track visitors.

The games

Owldoku, Slime Sliders, and CALC-U-LATOR are each built, hosted, and updated as their own separate products, on their own domains. Clicking through to play one of them takes you off this site, and that game's own privacy practices — including anything around ads, in-app purchases, or saved progress — apply from that point on, not this policy. If a game has its own privacy policy, it will be linked from within that game.

Third-party fonts

This page loads fonts from Google Fonts, which may see the request as part of serving them.

Hosting

This site is served as static files over standard web hosting infrastructure, which may log basic access information (like IP address and request time) as part of normal operation. I don't have separate access to that data beyond what my hosting provider makes available.

Children's privacy

This landing page doesn't knowingly collect information from anyone, including children, since it doesn't collect information at all. See the privacy policy of an individual game for how that game handles this.

Changes

If anything about how this site works ever changes in a way that affects privacy, this page will be updated and the date above will change.

Contact

Questions can be sent via Instagram.
